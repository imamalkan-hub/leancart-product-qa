# LeanCart Product Q&A

[![WordPress](https://img.shields.io/badge/WordPress-6.2%2B-21759b.svg)](https://wordpress.org/)
[![WooCommerce](https://img.shields.io/badge/WooCommerce-8%2B-7f54b3.svg)](https://woocommerce.com/)

Adds a Q&A section to the product page; you approve questions from the admin panel.

**Example site:** https://chimneylabguide.com
**Category:** Products · **License price:** $24 (Business Bundle: $149)

## Features
* Question form in a product tab
* Approve or reject from the admin
* Listing of approved questions
* Spam protection (nonce)

## Installation
1. Download the ZIP from `build/zips/` or download this repository as a ZIP.
2. In WordPress Admin, go to Plugins → Add New → Upload Plugin.
3. Activate the plugin and configure it at **Settings → LeanCart Product Q&A**.

## Requirements
- WordPress 6.2+, PHP 8.0+
- WooCommerce 8+ (HPOS compatible)
